# NumPy for AI/ML – Conceptual & Technical Assessment

This repository contains my **NumPy for AI/ML – Conceptual & Technical Assessment (Module 3)** completed using Python and NumPy.

The notebook covers NumPy concepts, array operations, vectorization, broadcasting, data preprocessing, numerical computations, and practical AI/ML scenarios.
